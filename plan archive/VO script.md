# SafeSteps — 60s pitch video · voiceover script

**148 words · target 57 seconds of speech in a 60-second frame · ~2.5 words/sec**

Read in second person. Read the **numbers slowly** — they're the credibility, and they're the
easiest thing to fumble. `//` marks a breath. Nothing in brackets is spoken.

---

## Continuous read (rehearse from this)

Ask a teenager to name IMDA's four online-safety actions. // Most can't. // They've seen the posters.

Posters tell you a rule. // They never let you feel what breaking it costs.

SafeSteps is a browser game that turns all four actions into decisions you live through.

Twelve scenarios, sixty-three choices. // Go public, and days later the strangers arrive — Privacy, Safety, Wellbeing all drop.

It scores near-misses too. // Commenting "don't do this" raises awareness — and still spreads the video.

Then it closes the real gap — walkthroughs of the actual apps. // Go private, and see what a stranger sees.

Eleven fact cards. // Fourteen cited sources. // Singapore police figures, and the psychology of why trends spread.

Scores stay hidden until the end. // Then four meters reveal whether you're a Boundary Boss — or a Digital Guardian.

No install, no accounts, no data collected. // Free to host. // The helplines are built in. // Ready to pilot.

## Delivery notes

- **Beat 2 is the thesis.** Slow down and land it. Everything after is evidence for this one line.
- **"sixty-three"** — say the words, don't read "63" as digits.
- **Beat 5's quote marks are audible.** Put a small lift on *"don't do this"* so it reads as
  something a person typed, not your own instruction.
- **Beat 6's em-dash is a real pause.** "Then it closes the real gap" — *stop* — "walkthroughs of
  the actual apps."
- **Beat 9 is four short statements, not one sentence.** Full stop between each. It should land like
  a checklist being ticked off.
- Read ~10% slower than feels natural. Nerves speed everyone up.

## If you run long

Trim in this order — never speed up the read:

1. Beat 7 → "Fourteen cited sources, including Singapore police figures." (8 words)
2. Beat 3 → "SafeSteps turns all four into decisions you live through." (10)
3. Beat 1 → "Ask a teenager to name IMDA's four safety actions. Most can't." (11)

**Never trim beats 2, 5 or 6** — the thesis, the distinctive mechanic, and the root-cause answer.
